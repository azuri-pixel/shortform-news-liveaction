# 「중요한 한 가지!」 강조 — key-callout@1

사용자 원문(2026-11-03): "0:46 여기서 중요한 한가지!는 매번 들어가는 대목인데, 이건 \"중요한 한가지!\" 흰색 글씨 굵게 중간에 넣고 노란색 밑줄을 넣어줘. ( 앞으로 만들 다른 영상들도 그렇게 쭉 해야해. )"

| 항목 | 값 |
|---|---|
| 기록 | 새 편은 `request.json` `key_callout: "key-callout@1"`(start가 기록). 이미 시작한 편은 `visual-system.json` `key_callout_policy`로 명시해 켠다. 확정된 옛 편에는 소급하지 않는다 |
| 조건 | 내레이션 문장이 「여기서 중요한 한 가지」로 시작(공백·문장부호 무시). 표현이 다르면(「중요한 건 하나」 등) 켜지지 않는다 |
| 화면 | 「중요한 한 가지!」 Pretendard 800 128px 흰색, 중심 x540·y860, 노란(#FFD16A) 밑줄이 문구 폭만큼 자란다. 공통 레이어(`KeyCalloutTrack`)가 그린다 — 장면 TSX에 넣지 않는다 |
| 시간 | 그 문장 시작 3f 전 ~ 문장 끝 + 10f. 자동 산출이다 |
| 자막 | 말자막은 그대로 켜 둔다 |

스타일 값의 정본은 `scripts/lib/key-callout.mjs`의 `KEY_CALLOUT_STYLE`이다. 바꾸려면 새 버전(`key-callout@2`)을 만든다. 장면 쪽에서는 이 구간에 큰 글자·도해를 겹치지 않게 설계한다.
